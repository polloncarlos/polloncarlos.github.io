Comparativo entre previsão do modelo e vendas reais nas lojas Rossmann.

01. Visão Geral

A rede varejista Rossmann precisava prever as vendas diárias de mais de 1.000 lojas para planejar estoque e alocação de recursos com até 6 semanas de antecedência.

O projeto cobre o pipeline completo: análise exploratória, feature engineering, seleção de variáveis, treinamento com validação temporal e deploy de API em produção com um diferencial: o modelo foi otimizado para rodar em ambiente com restrição real de memória de 512 MB.

02. Insights de Negócio

Lojas com competidores próximos apresentaram maior volume de vendas, sugerindo regiões com maior densidade de consumo.

Maior densidade competitiva associada a maior volume de vendas.

Promoções consecutivas mostraram redução gradual de performance, indicando desgaste do estímulo promocional ao consumidor.

Campanhas prolongadas demonstraram perda de performance.

03. Abordagem Técnica

  • Regressão com XGBoost e tuning automatizado com Optuna
  • Seleção de features com Boruta + ExtraTrees
  • Validação cruzada temporal (time series split) para evitar data leakage
  • RMSE ≈ 910 vs 1.120 do baseline redução de 19%
  • Otimização de memória para deploy em Render (512 MB free tier)

04. Deploy

A API Flask foi deployada no Render com restrições de memória reais. Um bot no Telegram permite que gestores consultem a previsão de vendas de qualquer loja digitando apenas o ID sem necessidade de acessar dashboards ou ferramentas técnicas.
